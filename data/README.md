# MySongbooks Nyimbo cia Agendi catalog inventory

The CSV contains 299 directory entries from the linked catalog. The JSON file contains each title, lyrics, source order, and source page URL for offline use. Directory order is not claimed to be the printed hymnal number. The source has one repeated title at entries 191 and 192 (Ningeekira Thuumbi), so there are 298 unique title strings.

The user states they own the source website and authorized this import. The inspected pages provide lyrics but no keyboard scores or key fields; those remain empty. The app keeps these entries in a separate source catalog and labels their numbers as directory order.

Source catalog: https://www.mysongbooks.scaptedesigns.com/library/nyimbo-cia-agendi
