Import authorized hymn content

Only import content with documented rights and human-verified Kikuyu text, numbering, musical keys, and cross-references. Records marked unverified or missing a license are rejected. This tool does not fetch hymnbooks.

Each row uses version (0 old, 1 new), number, title, lyrics, optional musicKey, crossReferenceNumber, and notationUrl, plus required contentLicense, licenseReference, and verified: true. For a cross-reference, include its verified target row in the same collection or import.
